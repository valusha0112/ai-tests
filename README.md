# ai-tests
# Мои учебные материалы по ИИ

## Для чего этот репозиторий
Здесь я собираю инструкции, примеры запросов и результаты учебных заданий.

## Что будет внутри
- prompts — примеры запросов к ИИ;
- notes — учебные заметки;
- homework — задания на вымышленных данных.

## Правила безопасности
- Не загружаю пароли, API-ключи, токены и резервные коды.
- Не загружаю данные учеников, клиентов и работодателя.
- Для примеров использую вымышленные данные.
- Репозиторий остаётся приватным.

## Как мне может помогать ChatGPT
Объяснять материалы, находить нужные файлы и предлагать улучшения.
